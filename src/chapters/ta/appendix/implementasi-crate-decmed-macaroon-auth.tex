\chapter{Implementasi \textit{Crate} \texttt{decmed-macaroon-auth}}
\label{lampiran:implementasi-crate-decmed-macaroon-auth}

\textit{Crate} \texttt{decmed-macaroon-auth} merupakan \textit{library crate} yang membungkus implementasi Macaroons untuk kebutuhan otorisasi DecMed. \textit{Crate} ini menyediakan API untuk penerbitan token awal, atenuasi delegasi, evaluasi \textit{caveat}, verifikasi akses segmen RME, pembentukan bukti delegasi, dan pembentukan kunci revokasi. Ringkasan API publik \textit{crate} ini terdiri atas 11 modul, 5 \textit{enum}, 12 \textit{struct}, 1 \textit{trait}, sekitar 38 fungsi publik, dan 6 \textit{re-export} dari \textit{crate} Macaroons dasar.

Tabel \ref{tab:api-publik-decmed-macaroon-auth} menunjukkan API publik yang diimplementasikan pada \textit{crate} \texttt{decmed-macaroon-auth}.

Secara fungsional, modul \texttt{caveats}, \texttt{effective}, \texttt{delegation}, dan \texttt{verify} membentuk inti evaluasi token. Modul \texttt{issuance} dan \texttt{attenuation} digunakan ketika token diterbitkan dan didelegasikan, sedangkan modul \texttt{wallet\_proof}, \texttt{delegation\_proof}, dan \texttt{revocation} menyediakan bukti tambahan serta kunci pencabutan yang digunakan oleh \textit{Server} PRE.
