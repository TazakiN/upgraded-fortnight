	Rekam Medis Elektronik (RME) menuntut kontrol akses yang menjaga kendali pasien sekaligus mendukung pelayanan kesehatan kolaboratif. DecMed sebagai kerangka kerja RME terdesentralisasi telah memanfaatkan IOTA, IPFS, dan Proxy Re-Encryption (PRE), tetapi masih memiliki tiga keterbatasan utama: pemberian akses bergantung pada penerbitan ulang oleh pasien, \textit{policy} akses bersifat \textit{coarse-grained} berbasis \textit{role} dan \textit{purpose}, serta data RME tersimpan sebagai objek besar yang sulit ditegakkan sesuai prinsip \textit{need-to-know}. Tugas Akhir ini merancang dan mengimplementasikan perluasan kontrol akses granular pada DecMed melalui tiga kontribusi. Pertama, model \textit{Policy-Based Access Control} (PBAC) digunakan untuk mendefinisikan hubungan aktor, objek RME, hak akses, dan kondisi akses, lalu direpresentasikan sebagai token Macaroon dengan \textit{caveats}. Kedua, data RME \textit{off-chain} disegmentasi berdasarkan \textit{dataset category} dan \textit{function category} agar \textit{policy} dapat ditegakkan pada unit data klinis. Ketiga, atenuasi token mendukung delegasi akses antartenaga kesehatan tanpa intervensi langsung pasien; pembentukan token turunan dimediasi \textit{Server} PRE agar cakupan turunan tidak melebihi token induk. PRE berperan sebagai mekanisme kriptografis pendukung distribusi kemampuan dekripsi dan sebagai titik penegakan sebelum data terenkripsi diproses. Prototipe mencakup segmentasi RME, token Macaroon, penegakan pada \textit{Server} PRE, \textit{smart contract} IOTA Move, serta penyesuaian \textit{Patient Client} dan \textit{Hospital Client} untuk alur rawat jalan dan rawat inap melibatkan petugas rekam medis, perawat, dokter, petugas laboratorium, dan apoteker. Pengujian dilakukan melalui skenario fungsional \texttt{P-KF-01} sampai \texttt{P-KF-12} dan pengujian nonfungsional \texttt{P-KNF-01} sampai \texttt{P-KNF-16}. Pada cakupan skenario uji dan batasan prototipe, kebutuhan fungsional dan nonfungsional yang diuji dinyatakan terpenuhi.

	\textbf{\textit{Kata kunci: Rekam Medis Elektronik, Policy-Based Access Control, Macaroons, Proxy Re-Encryption, IOTA}}
