	\small
	The transformation of electronic medical records (EMRs) requires access-control mechanisms that preserve patient control while supporting collaborative healthcare workflows. DecMed, as a decentralized EMR system, already uses IOTA, IPFS, and Proxy Re-Encryption (PRE); however, its previous mechanism still depended on patients to issue new access, did not represent token constraints with sufficient context, and stored EMR data as large objects that were difficult to enforce granularly. This thesis aims to design and implement an access-control extension for DecMed so that access can be constrained by actor, service context, data segment, validity period, and delegation chain. The proposed approach integrates Macaroon as an authorization token with caveats for attenuation, off-chain EMR segmentation based on dataset categories and clinical functions, metadata and audit recording on IOTA, and PRE as the authority enforcement point before encrypted data is retrieved or reprocessed for an access recipient. The implementation includes EMR segmentation components, Macaroon-based tokens, authority enforcement on the PRE Server, IOTA Move smart contracts, the Patient Client, and the Hospital Client for workflows involving patients, medical record officers, nurses, physicians, laboratory officers, and pharmacists. Testing was conducted through 12 functional scenarios for outpatient and inpatient workflows, as well as unit or integration tests from \texttt{PU-TA-01} to \texttt{PU-TA-09} for nonfunctional requirements. The evaluation states that all formulated functional and nonfunctional requirements were fulfilled. The results show that granular access control, EMR segmentation, limited delegation, revocation, auditing, and active-actor identity verification can be operationalized in DecMed within the evaluated prototype implementation boundaries.

	\textbf{\textit{Keywords: electronic medical records, granular access control, Macaroon, IOTA, Proxy Re-Encryption}}
\end{singlespace}
