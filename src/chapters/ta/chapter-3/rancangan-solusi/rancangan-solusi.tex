\section{Rancangan Solusi}
\label{sec:rancangan-solusi}

Berdasarkan hasil analisis solusi pada Subbab \ref{sec:analisis-solusi}, rancangan solusi difokuskan pada perluasan kontrol akses DecMed melalui model PBAC, representasi kapabilitas pada token Macaroons, segmentasi data, dan delegasi terbatas. Fondasi utama DecMed tetap dipertahankan pada rancangan ini, yaitu IOTA sebagai penyimpanan \textit{on-chain}, IPFS sebagai penyimpanan \textit{off-chain}, dan PRE sebagai mekanisme distribusi akses terhadap data terenkripsi. Arsitektur sistem, model kebijakan PBAC, token otorisasi berbasis Macaroons, segmentasi data \textit{off-chain}, penegakan otoritas pada \textit{Server} PRE, validasi subrole tenaga medis, pencabutan akses, audit, alur akses data, dan delegasi antar tenaga kesehatan tercakup dalam perancangan ini.
