\begin{abstract}
	Electronic medical records (EMRs) require access control that preserves patient authority while supporting collaborative care. The DecMed decentralized EMR framework already combines IOTA, the InterPlanetary File System (IPFS), and proxy re-encryption (PRE), but its previous design still depended on a new patient-issued grant for each recipient, authorized requests with coarse-grained JWT claims limited to role and read/update purpose, and stored clinical data as a comparatively large encrypted object. This work extends DecMed through three contributions aligned with that gap. First, a Policy-Based Access Control (PBAC) model relates actors, EMR objects, operations, and conditions, and Macaroon tokens carry the resulting capabilities as append-only caveats. Second, off-chain clinical data are segmented by dataset and function categories so those policies can be enforced on clinical units. Third, token attenuation supports delegation among healthcare actors without further patient involvement; child tokens are formed by the PRE Server so that parent capability, delegator identity, scope, and delegation chain are validated before issuance. PRE remains a cryptographic mechanism for distributing decryptability and a policy-enforcement point before encrypted data are processed; it does not replace PBAC or the token as the source of authorization decisions. The prototype covers outpatient and inpatient workflows involving medical-records personnel, nurses, physicians, laboratory personnel, and pharmacists. Evaluation used 12 functional scenarios (\texttt{P-KF-01}--\texttt{P-KF-12}) and 16 nonfunctional tests (\texttt{P-KNF-01}--\texttt{P-KNF-16}). Within the evaluated prototype scope and stated limitations, the documented mapped requirements were fulfilled.
\end{abstract}
